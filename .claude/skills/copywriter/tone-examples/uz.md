# Uzbek tone — professional companies

## Hero examples by sector

### B2B SaaS / tech startup (Latin, modern register)

**Headline:** Buxgalter ishini ikki barobar tezlashtiradigan dastur.
**Subhead:** Hisobotlar, soliqlar, hujjat aylanishi — bitta oynada. 14 kun bepul.
**Primary CTA:** Bepul boshlash

**Subhead:** 1200+ ob'yekt, 5 yil kafolat, o'z transportimiz va montaj brigadalarimiz.
**Primary CTA:** Narxni so'rash
**Secondary CTA:** Loyihalarimiz

**Primary CTA:** Xaridni boshlash

## Tone observations

- Modern Uzbek web copy is **moving away from Russian-style bureaucratic phrasing** ("samarali yondashuv asosida xizmat ko'rsatish", "yuqori sifatli mahsulotlar taqdim etamiz") toward short, direct sentences. Match the modern style for tech/startup/young brands; keep slightly more formal phrasing only for state-adjacent or traditional sectors.
- **Script choice signals audience.** Latin script reads as modern, urban, tech, startup, young. Cyrillic reads as traditional, older audience, government-adjacent. If unclear, ask. Mixing is OK only for brand names within either script.
- **Numbers and time spans land hard.** "14 kun", "1200+ ob'yekt", "2008-yildan beri", "4 soatda" — Uzbek readers respond to concrete proof in a market still full of vague promises.
- **Russian loanwords** are fine when they're standard tech vocabulary (kompyuter, internet, dastur), but reach for Uzbek alternatives when one exists and reads cleaner. Don't force purism either — sounding natural matters more than sounding "pure."
- **Avoid English hype-words transliterated** into Uzbek ("luxury tajriba", "premium xizmat"). They read as marketing-school amateur.

## Phrases to prefer over clichés

| Cliché (avoid) | Better (specific) |
| --- | --- |
| samarali natija | "2 baravar tezroq" |
| yuqori sifat | "5 yil kafolat" yoki aniq sertifikat nomi |
| zamonaviy yondashuv | aniq usul/texnologiya nomi |
| tez yetkazib berish | "Toshkentda 4 soat ichida" |
| individual yondashuv | "shaxsiy menejer", "loyiha bo'yicha shaxsiy hisobot" |
| kompleks yechim | qaysi xizmatlar kirishini ro'yxat qilib ko'rsatish |
| mukammal xizmat | mijoz fikri yoki aniq raqam (NPS, qaytaruvchi mijozlar %) |
